NODE.JS LOGIN PAGE - EASY RUN

WINDOWS:
1. Extract this ZIP.
2. Open the extracted folder in VS Code.
3. Double-click RUN-WINDOWS.bat
   OR in VS Code terminal run:
      npm install
      npm start
4. Browser: http://localhost:3000

LINUX / UBUNTU:
1. Extract ZIP and open folder in VS Code.
2. Terminal:
      chmod +x RUN-LINUX.sh
      ./RUN-LINUX.sh
   OR:
      npm install
      npm start
